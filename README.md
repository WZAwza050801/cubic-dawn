# Cubic Dawn / 方块黎明

仓库：[github.com/WZAwza050801/cubic-dawn](https://github.com/WZAwza050801/cubic-dawn)

做一个三维沙盒，世界的底座由方块与像素构成。

从最小可运行程序开始，由真实需求、Bug 和性能问题推动架构演化。

启动：`.\gradlew.bat run`

无窗口验收：`.\gradlew.bat verifyMath`

当前可以在已有岛上行走、跳跃、选中方块、删除和放置，并保存玩家与方块。进度见 `docs/implementation-progress.md`。

需要安装 **JDK 21**（不是仅 JRE）。Windows 使用 `./gradlew.bat run`，Linux/macOS 使用 `./gradlew run`。原生库自动选择平台；macOS 自动使用首线程启动。

完整无窗口检查：`./gradlew check`（Windows：`./gradlew.bat check`）。
使用临时存档启动：`./gradlew run -PworldFile=build/smoke-world.txt -Pframes=8`。

移动现在使用 60 Hz 固定模拟步，暂停/失焦会清空时间积累，长卡顿最多追赶 3 步。背包、木制合成、工作台和木工具已实现。


起步材料的沙子在第 **8** 格：放置后悬空会逐格下落，挖掉支撑会继续落下。暂停时沙子停止；F5 保存或正常退出后，下次启动会恢复待执行任务。新版存档 v6 兼容读取 v3/v4/v5，保存时自动升级。


按 **E** 打开/关闭 27 格背包，背包打开时游戏暂停。点击格子，再按 **1–9** 与对应快捷栏交换。快捷栏与背包里显示实际数量，每格最多 64 个。

按住左键采集方块，右键消耗当前格材料放置；背包满会拒绝采集并保留原方块。新世界和旧版存档首次升级获赠草、土、石、沙各 16 个，之后按实际数量保存，不会每次登录补发。

背包内按 **C**：4 沙 → 1 砂岩；按 **V**：4 石 → 4 石砖。配方为本项目当前规则，材料或输出空间不足均不扣材料。采集直接进入背包，暂不生成掉落实体。


新世界已有两棵树。旧世界可在背包中用 **4 土 → 1 树苗**，把树苗换到快捷栏，对草/土上方右键种植（完整树冠必须有空间，并避开玩家）。树苗暂时即时长成；采集 **4 树叶 → 1 树苗** 可继续种植。

背包中用 **↑/↓** 浏览全部配方，**Enter** 制作；C/V 原配方快捷键仍可用。新增原木 → 木板 → 木棍/工作台；站在工作台 3 格内可制作木镐、木斧和木锹。工具每格 1 个，选中后采集匹配材料更快，暂时没有耐久。

松开左键、换目标或工具、打开背包、暂停、失焦会取消采集进度，恢复后需重新按下。新配方和采集耗时是当前项目规则。

本批的逐步实现、提交、规则、测试和限制详见 [M09–M12 开发记录](docs/devlog/0002-wood-tools.md)；[Linux 窗口验收脚本](tools/smoke/README.md) 可复跑完整木材与工具流程。
