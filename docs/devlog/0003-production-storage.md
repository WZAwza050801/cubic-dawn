- 木工具最大耐久暂定 32 次；成功采集任意方块消耗一次，失败或中途取消不消耗。最后一次使用仍获得方块，随后工具消失。
- 堆栈增加剩余耐久字段；交换和移除保持耐久。旧 v6 工具按满耐久迁移，v7 保存剩余值；非工具耐久必须为 0。
- 验收：`check` 全通过，DURABILITY_FAIL/USE/TRANSFER/SAVE/BREAK/INVALID 覆盖失败不扣、成功扣一次、转移不修复、保存剩余值、耗尽消失和非法耐久拒绝。旧玩法全部回归通过。
