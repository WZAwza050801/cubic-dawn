# M13–M16：工具耐久、熔炉加工与箱子

目标：连续完成可保存的工具耐久、固定步加工、容器转移与实际窗口验证。每一步单独提交，记录规则、失败保护、验收和限制。本批不改写仓库 world.txt，不合并 main。

## M13 工具耐久（完成）

- 木工具最大耐久暂定 32 次；成功采集任意方块消耗一次，失败或中途取消不消耗。最后一次使用仍获得方块，随后工具消失。
- 堆栈增加剩余耐久字段；交换和移除保持耐久。旧 v6 工具按满耐久迁移，v7 保存剩余值；非工具耐久必须为 0。
- 验收：`check` 全通过，DURABILITY_FAIL/USE/TRANSFER/SAVE/BREAK/INVALID 覆盖失败不扣、成功扣一次、转移不修复、保存剩余值、耗尽消失和非法耐久拒绝。旧玩法全部回归通过。
- 修改点：Inventory.Stack、ItemIds、PlayerActions.mineBlock、SnapshotIO、Main 的手持/背包耐久显示。

## M14 熔炉与固定步生产（完成）

- 方块 ID 15 熔炉、16 箱子、17 玻璃；木炭物品 ID 206。熔炉需 8 石，箱子需 8 木板，两者都需邻近工作台。容器共享基础状态，箱子操作界面在下一步接入。
- 三格熔炉：输入/燃料/产物。沙→玻璃，原木→木炭，每件 120 模拟步（2 秒）。木板燃烧 300 步，原木 600，木棍 60，木炭 1200。这些是项目规则，不声明原版一致。
- 只有可加工输入且产物能接纳时才点火消耗一个燃料；已经点燃后即使输入空或产物堵塞仍继续耗尽燃烧时间，堵塞时加工进度冻结。移走输入会清空进度；不返还已消耗的燃料。
- 世界的每个固定步推进已加载熔炉；未加载格不加工。状态保存在 v8 的 box 记录里，包含输入、剩余燃料、输出、剩余燃烧和加工进度；v3–v7 继续可读，旧容器块初始化为空容器。
- SHA-256 覆盖容器全部状态；重复、孤立、缺失容器，非法种类/槽位数/燃烧时间/进度均拒绝解析。非空或仍燃烧的容器禁止拆除；空且熄灭后允许回收，避免内容丢失。
- 验收：`check` 全通过。FURNACE_HALF/RESTORE 验证中途保存恢复与连续运行相同；TWO/COLLECT/BREAK_GUARD/EMPTY_BREAK、CHARCOAL、REJECT_INPUT、OUTPUT_FULL_BAG、BLOCKED 覆盖产量、取出保护、燃料和堵塞。RATE_30/60/120/144 均在 2 秒模拟后得到同样产物与余燃。

## M15 箱子和容器界面（完成）

- 箱子 27 格，物品整堆双向转移，合并满堆后使用空格；接收方放不下时完全不动源物品，工具剩余耐久跟随物品，不能通过存取修复。
- 准星对准 5 格内熔炉/箱子按 F 打开；E 或 Esc 关闭。所有菜单都暂停世界，因此熔炉菜单显示“关闭菜单继续加工”，没有离线加工。
- 左侧点击选择背包：箱子 T 整堆存入；右侧点击选择储物格后 G 整堆取出。熔炉 T 放一个输入，B 放一个燃料，G 取全部产物，H/J 退回未加工输入/未消耗燃料。
- 容器转移成功后立即与玩家背包一起保存；状态不存在时关闭界面，未加载容器不能打开。背包配方界面保留；容器界面独立布局，最小窗口提高到 800×520。
- 窗口显示加工进度、剩余燃烧秒数、物品数量、操作提示；箱中选中工具显示剩余耐久。玻璃暂为实心不透明浅蓝方块，未加入透明渲染。
- 验收：CHEST_DEPOSIT/BREAK_GUARD/SAVE/FULL/WITHDRAW/EMPTY_BREAK/MERGE/FULL_DEPOSIT 检查保护、保存、满背包/满箱回滚、耐久和叠堆。窗口整链路在下一步记录。

## M16 保存、整链路与窗口回归（完成）

### 状态格式与兼容检查

- v7 新增工具耐久，v8 增加容器。玩家格格式为 `item 槽位 ID 数量 剩余耐久`；容器是 `box x y z 类型 余燃 加工进度 ID:数量:耐久 ...`。箱子须 27 格、熔炉须 3 格；空气必须为 0:0:0。
- v6 工具迁移为满耐久 32，原有材料和槽位不变；v7 现有耐久原样保留。旧容器方块缺少附属状态时初始化为空，v8 缺少容器状态则拒绝，避免悄悄抹掉内容。
- 新增 V6_TOOL_CONTAINER_MIGRATE、V7_WEAR_MIGRATE、FURNACE_PAUSE/UNLOADED、CONTAINER_INVALID/CHECKSUM/BACKUP。校验包括负余燃、进度越界、重复/孤立/缺失容器、篡改校验、缺主文件的备份恢复。
- DURABILITY_LAST_USE 通过真实采集事务验证最后一次使用仍获得一个石块，随后工具消失；不是只调用耐久递减函数。

### 实际窗口全过程

环境：Linux x64、Temurin JDK 21、LWJGL 3.4.3、Mesa OpenGL 4.5，独立 Xorg dummy `:98`。试验只写 build/production-smoke.txt，仓库 world.txt 未改。

1. 夹具：81 格土平台、熔炉与箱子各 1（83 方块）；背包沙 2、木板 2、耐久 31 的木镐 1、原木 1。
2. 对准熔炉按 F；T 两次加入两个沙，选择木板后 B 加一个燃料。保持菜单打开，F5 后模拟 tick 不变，确认菜单暂停世界。
3. 关闭菜单短暂运行，再打开保存：输入仍 2、加工约 0.9/2 秒、剩余燃料约 4.1 秒、输出为空。正常退出，确认保存了中途进度。
4. 重启同一世界，关闭菜单运行直至完成；再 F 打开，输出为玻璃 2、输入为空，按 G 收取，背包玻璃 2。
5. 横移到箱子，F 打开，选择木镐并 T 存入；箱中物品仍是 ID 201、数量 1、耐久 31，并在界面显示。
6. 关闭菜单，按住左键尝试采集非空箱子：日志为 container_not_empty，箱内工具未丢失。
7. 再次 F/G 取回工具：背包工具剩余耐久仍为 31。选择玻璃 T 存箱，箱内玻璃 2，正常退出。
8. 再次启动 frames=8 验证：83 方块不变；箱内玻璃 2；背包木板 1、原木 1、木镐 1（耐久 31）；熔炉三个格和余燃/进度均清空。

## 本批保留的简化

所有菜单暂停世界，不后台加工，也不离线追赶。燃料和合成耗时是项目规则；尚无九宫格配方、石/铁工具、漏斗、自动化与容器掉落实体。非空容器必须先清空、熔炉必须等余燃耗尽才能拆除。工具暂不支持修复。玻璃仍不透明，方块沿用颜色调试渲染，没有透明排序、纹理与照明。生命/饥饿、流体和分区网格仍未实现。
