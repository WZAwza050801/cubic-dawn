## M14 熔炉与固定步生产（完成）

- 方块 ID 15 熔炉、16 箱子、17 玻璃；木炭物品 ID 206。熔炉需 8 石，箱子需 8 木板，两者都需邻近工作台。容器共享基础状态，箱子操作界面在下一步接入。
- 三格熔炉：输入/燃料/产物。沙→玻璃，原木→木炭，每件 120 模拟步（2 秒）。木板燃烧 300 步，原木 600，木棍 60，木炭 1200。这些是项目规则，不声明原版一致。
- 只有可加工输入且产物能接纳时才点火消耗一个燃料；已经点燃后即使输入空或产物堵塞仍继续耗尽燃烧时间，堵塞时加工进度冻结。移走输入会清空进度；不返还已消耗的燃料。
- 世界的每个固定步推进已加载熔炉；未加载格不加工。状态保存在 v8 的 box 记录里，包含输入、剩余燃料、输出、剩余燃烧和加工进度；v3–v7 继续可读，旧容器块初始化为空容器。
- SHA-256 覆盖容器全部状态；重复、孤立、缺失容器，非法种类/槽位数/燃烧时间/进度均拒绝解析。非空或仍燃烧的容器禁止拆除；空且熄灭后允许回收，避免内容丢失。
- 验收：`check` 全通过。FURNACE_HALF/RESTORE 验证中途保存恢复与连续运行相同；TWO/COLLECT/BREAK_GUARD/EMPTY_BREAK、CHARCOAL、REJECT_INPUT、OUTPUT_FULL_BAG、BLOCKED 覆盖产量、取出保护、燃料和堵塞。RATE_30/60/120/144 均在 2 秒模拟后得到同样产物与余燃。

## M15 箱子和容器界面（完成）

- 箱子 27 格，物品整堆双向转移，合并满堆后使用空格；接收方放不下时完全不动源物品，工具剩余耐久跟随物品，不能通过存取修复。
- 准星对准 5 格内熔炉/箱子按 F 打开；E 或 Esc 关闭。所有菜单都暂停世界，因此熔炉菜单显示“关闭菜单继续加工”，没有离线加工。
- 左侧点击选择背包：箱子 T 整堆存入；右侧点击选择储物格后 G 整堆取出。熔炉 T 放一个输入，B 放一个燃料，G 取全部产物，H/J 退回未加工输入/未消耗燃料。
- 容器转移成功后立即与玩家背包一起保存；状态不存在时关闭界面，未加载容器不能打开。背包配方界面保留；容器界面独立布局，最小窗口提高到 800×520。
- 窗口显示加工进度、剩余燃烧步数、物品数量、操作提示；箱中选中工具显示剩余耐久。玻璃暂为实心不透明浅蓝方块，未加入透明渲染。
- 验收：CHEST_DEPOSIT/BREAK_GUARD/SAVE/FULL/WITHDRAW/EMPTY_BREAK/MERGE/FULL_DEPOSIT 检查保护、保存、满背包/满箱回滚、耐久和叠堆。窗口整链路在下一步记录。
