# 0001：建立最小窗口

## 本次目标

建立 Java、Gradle 和 LWJGL 项目，显示一个可以正常关闭的窗口。

## 本次没有实现

- 三角形和方块
- 摄像机
- 世界数据
- 玩家输入和移动
- 碰撞与物理
- 游戏架构

## 运行方式

Windows：

    .\gradlew.bat run

## 验收结果

- [x] Gradle 构建成功
- [x] 窗口正常显示
- [x] 控制台输出 Java、LWJGL 和 OpenGL 版本
- [x] Esc 可以退出
- [x] 关闭按钮可以退出
- [x] 退出后没有异常

窗口代码请求 960×540。系统缩放是 120 DPI（125%）。未声明 DPI 感知的测量进程看到的客户区是 768×432，换算后仍是 960×540。成功退出的两次运行没有异常。紧接着再启动一次时，出现过一次 WGL 无法创建上下文，报系统资源不足；稍后重试可以再次打开窗口。
