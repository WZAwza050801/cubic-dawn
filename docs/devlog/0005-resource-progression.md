## M22 界面、兼容及整链路验证（完成）

- 新世界使用资源岛生成入口；旧档仍按原快照加载，绝不自动改建。暂停后 O 才会转换原岛地下固定矿位的石块，非石块、空气和未加载格不动。**这些固定位置若已被玩家重新放成石块，也会转换**，因此入口放在暂停菜单并明确显示作用；不是自动升级。已挖空矿位不会重新填矿，重复操作无变化。
- 背包原有配方顺序不变，追加石/铁六种工具；上下键浏览、Enter 制作。原材料/工具名称和颜色补全，所有耐久上限改为按工具种类显示，不再写死 /32。
- 采矿时显示需要镐或需要石/铁镐，错误工具没有进度；原有旧材料仍能手采，不破坏旧玩法。
- IRON_WEAR_SAVE 验证铁镐磨损后剩余 191 可存档；ORE_BUILDING_PROTECTION 验证非石建筑不会被补矿覆盖。快照格式仍为 v9，无重发背包或覆盖旧世界。

### 实际窗口整链路

Linux x64、JDK 21、Mesa OpenGL、独立 Xorg :98。使用 build/resource-smoke.txt，原 world.txt 未改。

1. 夹具为 81 土平台+1 煤矿+3 铁矿+熔炉+工作台（87 格），背包木镐、石镐、木棍 2。
2. 木镐采煤，得到煤 1、耐久余 31；继续对铁矿按住左键，仍无粗铁，木镐耐久不变，显示石/铁镐门槛。
3. 换石镐采三块铁矿，得到粗铁 3、石镐余 93/96，方块数降至 83。
4. 横移到熔炉，放入粗铁 3、煤 1；关闭菜单运行后获得铁锭 3。
5. 取铁锭，在附近工作台打开配方，选择铁镐合成；消耗铁锭 3+木棍 2，得到耐久 192 的铁镐 1。
6. 正常退出后 frames=8 重启，保留三把镐（木 31、石 93、铁 192）和 83 方块，生命仍 20。
7. 另用无矿旧岛夹具运行暂停/O：出现煤矿和铁矿，总格数仍 1806。再次 O 后 revision 不变，确认不是反复增矿。
