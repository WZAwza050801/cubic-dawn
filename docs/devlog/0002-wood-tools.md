# M09–M12：树木、木制品、工具和持续采集

本批目标：在 M08 的有限背包上，连续完成树木资源、木材合成、工作台与工具、固定步采集，并逐步验证。所有规则是项目暂定规则，不声明对齐某个 Minecraft 版本。原有 world.txt 不改写；已有建筑与物品数量必须保留。

## 步骤 1：树木与可再生木材（完成）

- 为原木、树叶、木板、工作台分配稳定方块 ID 11–14，树苗物品 ID 205。
- 保留旧 generateIsland 作为地形验收基线；新增可玩世界生成入口，在远离出生点的固定位置生成两棵树。
- 树木由 3 格树干、两层树冠和顶叶组成。种植必须踩在草/土上，所有目标格已加载且为空，避开玩家；全树校验通过后一次提交，失败不覆盖建筑、不扣树苗。
- 已有存档不自动补树；下一步提供泥土换树苗配方，保证旧岛也能进入木材流程。
- 验收：`check` 全通过；TREE_SEED/BUILDING/BODY/UNLOADED/PLANT/BOUNDARY 覆盖确定性、42 个新树块、建筑保护、身体保护、未加载与边界、重复命令。地形基线和存档回归全部通过。
- 本步只建立世界模型与测试；窗口接入在步骤 3 一并完成。

## 步骤 2：多材料合成、工作台与工具（完成）

- 原木 1→木板 4；木板 2→木棍 4；木板 4→工作台 1；泥土 4→树苗 1。泥土配方专用于旧岛进入可再生木材流程，不自动给旧存档补树、不重发起步材料。
- 木镐/木斧各需木板 3+木棍 2；木锹需木板 1+木棍 2。工具配方要求玩家眼睛距已加载工作台中心 ≤3 格，不要求视线，隔墙也可用（本项目简化）。

- 右键树苗调用步骤 1 的完整树木事务，通过后才扣一棵；树即时长成，不是延迟生长，叶子暂不衰减。
