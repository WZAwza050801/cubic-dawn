# M17–M19：安全重生、坠落与生命保存

本批不修改仓库 world.txt，不合并 main，保留所有物品/工具耐久/容器。规则为本项目暂定规则。

## M17 安全落点（完成）

- 按距原出生列 (2,3) 的方形环顺序搜索已加载实心地面，先找较近列，再找高处；身体必须完全处于已知空气内。
- 不覆盖建筑、不清空方块、不生成临时地面；空世界找不到落点时明确失败。
- 验收：SPAWN_CLEAR/DETERMINISTIC/EMPTY/UNKNOWN/SUPPORTED/INVALID_POSITION 全通过；检查可用落点、确定性、空岛不修改、未知格拒绝、地面支撑与非法位置。既有 check 全部通过。

## M18 生命、坠落与存档（完成）

- 最大生命 20；落地时超过约 3 格的部分向上取整扣血（3.01 格阈值抵消碰撞浮点误差）；同次落地只扣一次，普通跳跃不扣血。眼睛低于 -24 时虚空死亡。
- v9 玩家状态增加生命、竖直速度和本次坠落最高点；保存重进继续同一次坠落，不通过重进重置伤害。旧 v3–v8 玩家默认满血、静止，最高点为当前位置；容器/背包格式保持不变。
- 验收：FALL_DAMAGE/ONCE/JUMP_SAFE、VOID_LETHAL、VITALS_SAVE/INVALID、FALL_RESTORE、FALL_FRAMERATES 全通过；30/60/120/144 FPS 从同高度落下得到相同生命。既有 check 全部通过。

## M19 界面、取消与完整验收（完成）

- HUD 显示 HEALTH/20；死亡后停止移动、采集和世界模拟，显示 R 重生提示。Esc 仍可打开暂停菜单，Q 退出，F5 可以保存死亡状态。
- R 仅在死亡且未打开暂停菜单时有效。重生恢复满血、清空下落速度/采集进度，要求重新按下左键；保留原背包、所有工具剩余耐久、箱子、熔炉和世界方块，不发起步材料、不掉落物品。
- 找不到安全地面时留在死亡状态并提示重试，不凭空建平台、不删除障碍物。加载仍存活但位置在世界范围外或埋在方块里的玩家时，尝试安全重定位；失败则保持死亡状态。
- 新增 V8_HEALTH_MIGRATION（旧版默认满血和静止）、VITALS_CHECKSUM、DEATH_SAVE。旧存档与容器/物品检查全部回归通过。

### 窗口验收经过

Linux x64、JDK 21、Mesa OpenGL、独立 Xorg :98，临时文件 build/survival-smoke.txt。

1. 建立 1807 方块夹具（岛和树木，加一个箱子），箱内玻璃 3；背包有耐久 7 的木镐和泥土 5。玩家 y=12、生命 2、竖直速度 -1。
2. 实际启动游戏并落地，死亡保存日志出现；F5 后读取生命为 0，界面显示死亡提示和 HEALTH 0/20。
3. 按 R：生命恢复 20，在 (2,3) 列安全地面上重新站立；工具仍耐久 7，泥土仍为 5，箱内玻璃仍为 3。
4. 截图后正常 Esc/Q 退出；frames=8 再启动，世界仍为 1807 方块，生命/背包/容器与前次一致。世界 revision 保持 4，未为重生改写地形。
