## 坐标

画面里的方块编号 `(x,y,z)` 仍以该整数为中心，占据 `[x-0.5, x+0.5)`。
规格里的格子 `[x, x+1)` 由眼睛坐标加 0.5 换算，距离和法线不变，格子编号与画面相同。
+Y 向上。偏航 0 看向 -Z，偏航增加向右转，俯仰增加抬头。
玩家眼睛在身体中心，半宽 0.3，半高 0.9。这是本项目的身体尺寸。

## M07 第一部分：固定移动步

移动和重力以 60 Hz 计算，渲染独立采样。每帧最多接纳 0.05 秒、执行 3 步；超出的真实时间丢弃，不积累追赶债务。暂停、失焦及恢复时清空余量和待处理跳跃，并重置采样时间。短按跳跃保留到下一个模拟步，在一帧执行多步时只消费一次。视角、快捷栏和编辑仍按渲染帧采样；这不是完整的输入录像系统。

新增 TIME01–03、TIME_JUMP、TIME_INVALID：30/60/120/144 FPS 的同一持续输入，模拟位置与竖直速度逐值相同；暂停不推进；一小时挂起最多追赶 3 步；短按不丢失也不重复；无效时间值不破坏后续计时。

构建不再绑定开发者 Windows JDK 路径，需安装 JDK 21。LWJGL 原生库按 Windows/Linux/macOS 和 x64/arm64 自动选择，macOS 使用首线程启动；仅 Linux 构建在本轮验证。Gradle Wrapper 改用官方分发地址，`check` 会执行 `verifyMath`。

本轮未修改 `world.txt` 和快照格式。本段为上一轮记录；可保存延迟任务已在下文完成。窗口交互尚未在本轮人工验收。

本轮验收：Linux x64、Temurin JDK 21，Gradle 8.14.3 `check` BUILD SUCCESSFUL；新增及原有无窗口检查全部 PASS。云环境构建通过本机代理与系统 CA 信任库访问 Maven Central，未在仓库写入代理配置。


## M07 第二部分：可保存方块任务与沙子

新增方块 ID 8：沙子，快捷栏第 8 格（数字键 8 或滚轮）。仍为不限量建造测试栏。放在侧面或上方后，每 6 个模拟步（0.1 秒）检查一次，悬空则原子地向下移动一格。挖掉支撑会唤醒上方沙子，堆叠会继续下落。不生成掉落实体，不造成伤害；世界下边界暂时托住沙子。这是本项目规则，尚未声称与指定 Minecraft 版本一致。

`BlockTicks` 用模拟时间记录到期步数；同一格合并，执行顺序固定为到期步数、x、y、z，每模拟步最多 256 个任务，超出留在队列中。玩家身体和未加载空间会阻止下落并重试，过期任务不会移动已换成其他材料的方块。暂停、失焦、退出期间都不推进任务，没有离线追赶。

快照升到 v5：校验覆盖模拟步数与全部待执行 `fall` 任务；仍先写临时文件再替换并保留 `.bak`。v3/v4 继续可读，旧档默认模拟时间为 0、队列为空，下一次保存升级至 v5。未知方块 ID 继续保留。非法坐标、负步数、重复任务或缺失时钟均拒绝加载。仓库原有 `world.txt` 未改写。
